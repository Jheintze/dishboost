# DishBoost 🍽️

DishBoost is an AI-powered marketing assistant designed to help restaurants create engaging promotional content.

The application transforms restaurant information, promotions and food photos into ready-to-use marketing content for Instagram, Facebook and Google Business.

**Project status:** Early-stage prototype – currently in development and validation.

## Features

- Generate marketing content using AI
- Create promotional content based on restaurant information and offers
- Use food photos as input for content generation
- Prepare content for Instagram, Facebook and Google Business

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- OpenAI API

## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Jheintze/dishboost.git
   cd dishboost
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure the required environment variables in a `.env.local` file.

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
